# Character Counter

## 📌 Project Description
A simple and interactive character counter built using HTML, CSS, and JavaScript. It displays the number of characters entered and the remaining characters allowed in real time as the user types.

## ✨ Features
- Real-time character counting
- Displays the total number of characters typed
- Shows the remaining characters allowed
- Maximum character limit
- Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎯 Learning Objectives
- Understanding JavaScript events
- Using the `input` event listener
- DOM manipulation
- Working with the `value` and `length` properties
